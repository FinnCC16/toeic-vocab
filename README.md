# TOEIC Vocab｜多益例句學習

以例句為核心的多益單字／片語學習 PWA。

## 使用方式
1. 開啟 GitHub Pages 網址。
2. iPhone 使用 Safari 開啟。
3. 點選「分享」→「加入主畫面」。
4. 首次開啟時保持網路連線，讓離線快取完成。

## 功能
- 先讀例句、再顯示單字與中文意思
- 不會／不熟／會了評級
- 自動安排複習
- 每日學習目標與例句測驗
- 本機保存學習紀錄，可匯出／匯入備份

## 注意
- 學習紀錄保存在目前瀏覽器的本機儲存空間，不會自動跨裝置同步。
- 目前詞庫中只有已建立例句的詞條可直接學習；其餘詞條保留在詞庫並標示待補例句。
- 發音使用裝置內建語音合成，語音資源與離線支援依裝置而異。
